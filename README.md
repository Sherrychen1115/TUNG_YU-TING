# 股市上漲是否代表整體經濟變好？

## ——以台灣股市、經濟成長與實質薪資之關係為例

## 研究目的

台股在近十年屢創新高，但一般受薪者未必感受到「經濟變好」。本專題用 2015–2025 年的年度資料，比較**股市表現**、**經濟成長**與**實質薪資**三者的變動，看看股市上漲是否同時代表整體經濟與勞工所得的改善。

## 研究期間

- 分析期間：**2015–2025 年**（共 11 個年度）
- 2014 年資料只用來計算 2015 年的年增率，不列入分析

## 研究問題

1. **股市與經濟成長**：台股加權指數的年報酬率與實質 GDP 成長率是否同方向變動？兩者的相關程度如何？
2. **股市與實質薪資**：台股加權指數的年報酬率與實質經常性薪資年增率是否同方向變動？兩者的相關程度如何？
3. **三者是否同步**：股市、經濟成長、實質薪資三者在哪些年份同步上升，哪些年份出現背離（例如股市大漲但實質薪資停滯或下降）？

## 資料來源

| # | 變數 | 資料來源 | 頻率 | 本專題使用的指標 |
|---|------|----------|------|------------------|
| 1 | 臺灣證券交易所發行量加權股價指數（TAIEX） | 臺灣證券交易所 https://www.twse.com.tw | 日資料 → 換成年資料 | 年底收盤指數、年報酬率（%） |
| 2 | 實質 GDP 成長率（經濟成長率） | 行政院主計總處「國民所得統計」 | 年 | 實質 GDP 成長率（%） |
| 3 | 實質經常性薪資 | 行政院主計總處 薪資及生產力統計 | 年 | 工業及服務業受僱員工每人每月實質經常性薪資（元）、年增率（%） |

### 變數定義

- **股市年報酬率** = (當年年底收盤指數 ÷ 前一年年底收盤指數 − 1) × 100%
- **實質 GDP 成長率**：直接使用官方公布數字
- **實質薪資年增率** = (當年實質經常性薪資 ÷ 前一年實質經常性薪資 − 1) × 100%

## 需要手動下載的資料

下載後放進 `data/raw/`，**檔名照下表取**，原始檔內容不要修改。檔案若是 `.xlsx` 或 `.csv` 都可以，保留原本的副檔名即可。

### 1. 臺灣證券交易所加權股價指數

- **網站**：臺灣證券交易所 → 交易資訊 → 盤後資訊 → **每日市場成交資訊**
- **要下載的範圍**：2014–2025 年**每年 12 月**的資料（共 12 個檔案）。表格中的「發行量加權股價指數」欄就是每日收盤指數，分析時取 12 月最後一個交易日當作年底收盤。
- **存放位置與檔名**：直接放在 `data/raw/` 根目錄，保留證交所下載時的原始檔名

  ```
  data/raw/FMTQIK_201412.csv
  data/raw/FMTQIK_201512.csv
  ...
  data/raw/FMTQIK_202512.csv
  ```

### 2. 實質 GDP 成長率

- **網站**：行政院主計總處 → **國民所得統計** → 國民所得重要指標 → **經濟成長率**，年資料（103–114 年）
- **要下載的範圍**：2014–2025 年
- **存放位置與檔名**：

  ```
  data/raw/GDP.xls
  ```

### 3. 實質經常性薪資

- **網站**：行政院主計總處 → 薪資及生產力統計 → 薪情平臺 → **工業及服務業、總計、每人每月實質經常性薪資**（統計值與較上年同期增減率），年資料
- **要下載的範圍**：2014–2025 年
- **存放位置與檔名**：保留薪情平臺匯出時的原始檔名（含匯出時間）

  ```
  data/raw/薪情平臺匯出資料_YYYYMMDDhhmmss.xlsx
  ```

  `data/raw/` 中只能有一個這種檔案，程式才知道要讀哪一個。

### 整理資料

原始檔放好後，在專案根目錄執行：

```
uv run python analysis/etl.py
```

會產生 `data/clean/annual_2014_2025.csv`（UTF-8 with BOM），欄位為 `year`、`taiex_close`、`taiex_return`、`gdp_growth`、`real_wage`、`real_wage_growth`。缺值保留空白，不補值（例如 2019 年的實質薪資年增率，官方因統計範圍擴增不與前一年比較）。

### 下載紀錄

官方數字會修正（尤其 GDP 和最近一年的薪資），請在下載時記下日期：

|------|----------|------|
| FMTQIK_201412.csv ～ FMTQIK_202512.csv | | |

## 研究限制

- 年度資料只有 11 個觀察值，相關分析只能看出趨勢，無法做因果推論或嚴謹的統計檢定。
- 加權指數高度集中在少數大型電子股，股市漲幅不一定代表多數產業。
- 2025 年的 GDP 與薪資數字可能仍是初步統計，日後會修正。
